# 🚀 Laravel News - Modern Multi-Language Portal & Theme

A feature-rich, high-performance web portal theme inspired by the Laravel ecosystem, featuring real-time multi-language translation, dark/light mode toggle, dynamic article filtering, text-to-speech audio narration, and bookmarks.

---

## 🌟 Key Features

* **🌐 7-Language Live Translation:**
  * English (🇺🇸), हिन्दी / Hindi (🇮🇳), Español / Spanish (🇪🇸), Français / French (🇫🇷), Deutsch / German (🇩🇪), 日本語 / Japanese (🇯🇵), and العربية / Arabic (🇸🇦 with native RTL support).
  * Seamless client-side dynamic content & UI translation without page reloads.
* **🌓 Dark & Light Themes:**
  * High-contrast, sleek dark mode by default with glowing Laravel red accents (`#FF2D20`).
  * Easily toggleable light mode with persistence across sessions via `localStorage`.
* **🔍 Instant Search & Category Filtering:**
  * Real-time search across titles, descriptions, and tags.
  * Categories: *All Updates, News, Tutorials, Packages, Releases, Podcasts, Community*.
* **📑 Grid & List View Switcher:**
  * Toggle between card grid view and dense list view with a single click.
* **🔊 Text-to-Speech (Article Audio Reader):**
  * Built-in Web Speech API audio narration to listen to full stories on the go.
* **🔖 Local Bookmarks Drawer:**
  * Save favorite articles to read later, stored persistently in the browser.
* **📱 100% Responsive Design:**
  * Optimized for desktop, tablet, and mobile screens.

## ⚡ Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/satyam-ai18/News-Theme-.git
   ```

2. **Open the project:**
   Simply double-click or open `index.html` in any modern web browser (Google Chrome, Edge, Brave, Firefox, Safari).

   Or launch using a local static server (e.g., VS Code Live Server / Python):
   ```bash
   python -m http.server 8000
   ```
